# CQAI Club · GitHub 组织主页

本仓库维护 [cqai-club](https://github.com/cqai-club) 的公开组织主页。

- `profile/README.md`：GitHub 组织 Overview 中展示的介绍与项目导航。
- `profile/assets/cqai-banner.svg`：主页横幅，使用仓库内的静态矢量图。

修改默认分支中的 `profile/README.md` 后，GitHub 会更新组织主页。项目介绍与入口应以对应公开仓库和 [俱乐部官网](https://cqaiclub.asia/) 的当前信息为准。

此仓库只承载组织展示内容，各项目的贡献约定与许可由各仓库单独维护。
